# UPI Transaction Analytics Dashboard

## 📊 Overview

An interactive **UPI Transaction Analytics Dashboard** built using **Microsoft Power BI** to analyze transaction patterns, trends, and key performance metrics.

The dashboard transforms raw UPI transaction data into clear and interactive visualizations, helping users explore transaction activity across different dimensions and time periods.

## 🎯 Objectives

* Analyze UPI transaction trends over time
* Identify transaction patterns across different categories
* Compare transaction performance across segments
* Provide interactive filtering for detailed analysis
* Present insights through a clean and user-friendly dashboard

## 🛠️ Tools & Technologies

* **Power BI** – Data visualization and dashboard development
* **Power Query** – Data cleaning and transformation
* **Excel/CSV** – Data source
* **GitHub** – Project documentation and version control

## 📈 Dashboard Features

* Interactive slicers for dynamic filtering
* Time-based transaction trend analysis
* Category-wise transaction analysis
* Comparative charts for identifying patterns
* Dashboard navigation using bookmarks
* Detailed transaction-level analysis through matrix visuals

## 🔄 Data Preparation

The dataset was prepared using **Power Query**, including data cleaning, transformation, formatting, and preparation of fields required for analysis and visualization.

## 💡 Key Insights

The dashboard helps identify:

* Changes in transaction activity over time
* High and low-performing transaction categories
* Differences in transaction patterns across segments
* Periods with higher or lower transaction activity
